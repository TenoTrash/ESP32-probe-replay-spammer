# ESP32-probe-replay-spammer
Simple pero efectivo WiFi probe request spammer

Bastante configurable para que pueda escanear canales con o sin adyacencias, tiempos, etc.
Siempre es interesante ver los resultados y se puede usar en combinación con otras herramientas.
Dado que consume muy poco, puede usarse directamente con un cable USB-C a USB-C y un celular, como para poder ir viendo la terminal en vivo.
